# 제작 의도 (요약)

자세한 이유는 [INTENT.md](INTENT.md), 동작 설명은 [IMPLEMENTATION.md](IMPLEMENTATION.md)에 있다.

## 설계 이유

AI가 쓴 글은 믿을 수 없다고 전제했다. AI는 글자 수를 넘기고, 영상에 없는 말을 지어내고, "사주 봤는데 맞더라" 같은 가짜 후기를 쓴다. 그래서 역할을 셋으로 나눴다.

1. **AI는 초안만 쓴다.** 영상의 고민을 한 줄로 요약한 뒤 댓글을 쓰고, 댓글에서 짚은 영상 속 말(`detail`)을 자막 그대로 함께 적는다.
2. **검사기가 판단한다.** AI 초안과 사람이 고친 글이 같은 검사기를 지난다. 떨어지면 이유("132자, 기준 40~120자")를 붙여 AI에게 다시 쓰게 한다 (최대 3번).
3. **서버가 강제한다.** 화면에서 버튼을 끄는 것은 안내다. 게시 직전에 서버가 검사기와 운영 규칙을 다시 돌린다.

기본 게시 범위는 "본인 테스트 영상만"이다. 이 방식의 댓글은 유튜브 스팸 정책과 표시광고법에 걸릴 수 있어서, 지정 채널 게시는 설정을 직접 바꿔야 켜진다.

## 검증기

| 규칙                          | 검사 방법                                                                         |
| ----------------------------- | --------------------------------------------------------------------------------- |
| 40~120자, "운명원" 정확히 1번 | 글자 수와 등장 횟수를 센다                                                        |
| 링크·해시태그 없음            | 전각 문자, "닷 com" 같은 모양 바꾼 링크까지 잡는다                                |
| 가짜 후기 없음                | "운명원"이 든 문장의 "봤는데·맞더라"를 막는다. "영상 봤는데"는 허용한다           |
| 영상을 봤다는 증거            | `detail`이 실제 자막에 있거나, 댓글이 영상 자료와 6글자 이상 연속으로 겹쳐야 한다 |
| 반복 금지                     | 다른 영상에 쓴 댓글과 너무 비슷하면 막는다                                        |

## 규칙을 강제하는 위치

모든 규칙은 `POST /api/post`가 게시 직전에 확인한다. 화면이 보낸 값은 믿지 않는다.

- **허용 채널:** 서버가 yt-dlp로 받은 채널 ID로만 판단한다.
- **영상당 1개:** 계정과 상관없이 센다. 영상 ID는 11자리 형식만 받아 `ID&t=1` 같은 우회를 막는다.
- **하루 10개:** 한국 시간 기준.
- **확인 안 된 게시도 센다:** 버튼은 눌렀는데 내 댓글이 안 보이면 `unverified`로 남긴다. 실제로 올라갔을 수 있으므로 재게시를 막는다.
- **동시 게시 차단:** 검사 시작 전에 잠근다.
- 차단된 시도도 이유와 함께 SQLite 기록에 남는다.

다른 AI에게 규칙 우회를 맡겨 7건을 찾았고, 각각을 테스트로 만든 뒤 고쳤다. 자동 테스트는 79개다. 본인 테스트 영상에 실제로 게시해 댓글이 공개된 것을 따로 확인했다.

## 버린 시도

- **Node.js 서버 → FastAPI:** yt-dlp를 코드에서 바로 부르려고 옮겼다.
- **YouTube Data API, 로컬 AI 모델:** 심사자가 키를 만들거나 8GB 모델을 받아야 해서 뺐다. 대신 RSS·yt-dlp와 무료 Gemini(한도 초과 시 Groq)를 쓴다.
- **Gemini Flash-Lite:** 매번 120자를 넘기거나 같은 문장을 반복했다. 실제 영상 11건 비교 후 3.5 Flash로 정했다.
- **"버튼 클릭 = 성공":** 올라갔는지 알 수 없어서, 내 댓글이 보여야 성공으로 바꿨다.
- **화면에서만 규칙 막기:** 요청을 직접 보내면 우회된다. 서버 검사로 바꿨다.
